# Υπενθυμίσεις καταστημάτων

Εφαρμογή Windows 10/11 στα ελληνικά για κοινές υπενθυμίσεις σε πολλά καταστήματα.

- Φτιάχνεις **εκδήλωση με ώρα** σε Google Calendar (όχι Tasks).
- Σε κάθε PC εμφανίζεται μεγάλο παράθυρο στο κέντρο της οθόνης, πάνω από τα άλλα προγράμματα.
- Ο υπάλληλος πατά **Το είδα** ή **Σε 5 λεπτά**.
- Δεν χρειάζεται login Gmail στον υπολογιστή. Μόνο μυστικό ICS link στις ρυθμίσεις.
- Το «Το είδα» ισχύει **μόνο σε εκείνο το PC**. Τα άλλα μαγαζιά συνεχίζουν να τη βλέπουν.

Δεν χρησιμοποιεί ειδοποιήσεις Outlook / Windows Notification Center / Focus Assist. Είναι δικό της παράθυρο και δικός της ήχος (`chime.wav`).

## Γρήγορη εγκατάσταση (χωρίς Python)

1. Κατέβασε το **`Ypenthimiseis-Setup.exe`** (δωρεάν):
   - από την επίσημη σελίδα **<https://localbits.gr/ypenthimiseis/>**, ή
   - από τα **Releases** του GitHub: <https://github.com/n1kcha/ypenthimiseis/releases/latest> (απευθείας λήψη: <https://github.com/n1kcha/ypenthimiseis/releases/latest/download/Ypenthimiseis-Setup.exe>).
2. Διπλό κλικ στο `Ypenthimiseis-Setup.exe`. Δεν χρειάζεται διαχειριστής.
3. Αν βγει μπλε παράθυρο **«Τα Windows προστάτευσαν τον υπολογιστή σας»** (SmartScreen): πάτα **«Περισσότερες πληροφορίες»** → **«Εκτέλεση ούτως ή άλλως»**. Βγαίνει επειδή το πρόγραμμα δεν έχει ψηφιακή υπογραφή.
4. Συμπλήρωσε **όνομα καταστήματος**, **ID καταστήματος** (λατινικά γράμματα ή/και αριθμοί, π.χ. `peristeri` ή `12`) και **κεντρικό σύνδεσμο ICS** (βλ. ενότητα 1). Τα επιπλέον ημερολόγια και τα δευτερόλεπτα ήχου είναι προαιρετικά.
5. Τέλος. Η εφαρμογή ανοίγει στο tray (κίτρινο τετράγωνο κοντά στο ρολόι) και ξεκινά μόνη της με τα Windows.

Αλλαγές αργότερα: εικονίδιο στο tray → **Ρυθμίσεις** (ισχύουν αμέσως, χωρίς επανεκκίνηση). Υπάρχει και συντόμευση «Ρυθμίσεις υπενθυμίσεων» στο μενού Έναρξη.

Ημερολόγια στις Ρυθμίσεις: **＋ Προσθήκη** ανοίγει παράθυρο με μεγάλο κουτί για τον σύνδεσμο (Ctrl+V, δεξί κλικ → Επικόλληση ή «Επικόλληση από πρόχειρο»), προαιρετικό όνομα και επιλογή «Κεντρικό ημερολόγιο». Το **Έλεγχος** κατεβάζει το ημερολόγιο και δείχνει πόσα γεγονότα βρήκε. **Αλλαγή** (ή διπλό κλικ) και **Αφαίρεση** για τα υπάρχοντα.

Στην υπενθύμιση: **Enter** = «Το είδα», **Esc** = «Σε 5 λεπτά».

- Εγκαθίσταται στο `%LOCALAPPDATA%\Ypenthimiseis` (εκεί είναι και τα `config.json`, `state.json`, `chime.wav`).
- **Ενημέρωση:** τρέξε απλώς το νέο Setup. Κλείνει την παλιά έκδοση και κρατά τις ρυθμίσεις και τα «Το είδα». Αν υπήρχε η παλιά έκδοση με Python, αφαιρείται η παλιά συντόμευση εκκίνησης.
- **Απεγκατάσταση:** Ρυθμίσεις Windows → Εφαρμογές → «Υπενθυμίσεις καταστημάτων» → Κατάργηση εγκατάστασης. Κλείνει την εφαρμογή και αφαιρεί την αυτόματη εκκίνηση.
- Αν κάποιο antivirus μπλοκάρει το αρχείο, είναι συνήθως ψευδής συναγερμός για προγράμματα φτιαγμένα με PyInstaller· πρόσθεσε εξαίρεση ή χρησιμοποίησε την εγκατάσταση με Python (τέλος της σελίδας).
- Στα Windows 11 έλεγξε **Ρυθμίσεις → Εφαρμογές → Εκκίνηση** ότι το «Ypenthimiseis» είναι **On**.

## 1. Κεντρικό ημερολόγιο (μία φορά)

1. Google Calendar → νέο ημερολόγιο, π.χ. `Υπενθυμίσεις καταστημάτων`.
2. Σε υπολογιστή: γρανάζι ⚙ πάνω δεξιά → **Ρυθμίσεις**.
3. Στη λίστα αριστερά, κάτω από «Ρυθμίσεις για τα ημερολόγιά μου», πάτα το όνομα του ημερολογίου για να ανοίξουν οι επιλογές του.
4. Διάλεξε **Ενσωμάτωση ημερολογίου** και αντέγραψε τη **Μυστική διεύθυνση σε μορφή iCal** (τελειώνει σε `.ics`).
5. Μην το κάνεις δημόσιο. Όποιος έχει το link διαβάζει τα γεγονότα.

Γεγονότα: τύπος **Εκδήλωση**, με συγκεκριμένη ώρα (όχι ολοήμερο αν θέλεις popup ακριβώς τότε). Ζώνη ώρας Ελλάδας.

Το Outlook μπορεί να δώσει ICS (δημοσίευση ημερολογίου), αλλά συχνά αργεί περισσότερο και σε εταιρικό tenant μπορεί να είναι κλειστό. Το Proton Calendar έχει share link αλλά το feed συχνά δεν ανανεώνεται έγκαιρα. Προτείνεται το Google Calendar.

## 2. config.json

| Πεδίο | Νόημα |
|---|---|
| `store_name` | Εμφανίζεται πάνω στο παράθυρο υπενθύμισης |
| `store_id` | Κωδικός για στόχευση με αγκύλες: λατινικά γράμματα ή/και αριθμοί, π.χ. `peristeri`, `12`, `peristeri2` |
| `ics_url` | Κεντρικό μυστικό ICS (ίδιο σε όλα τα μαγαζιά) |
| `ics_urls` | Επιπλέον ημερολόγια (λίστα). Π.χ. ημερολόγιο εργαζομένων **μόνο** στα PC εκείνου του μαγαζιού |
| `ics_names` | (προαιρετικό) Ονόματα ημερολογίων για τη λίστα των Ρυθμίσεων: `{"σύνδεσμος": "όνομα"}` |
| `poll_seconds` | Κάθε πότε ρωτάει τα ημερολόγια (προεπιλογή 30) |
| `minutes_before` | 0 = στην ώρα του γεγονότος. 5 = πέντε λεπτά νωρίτερα |
| `show_missed_max_minutes` | Αν το PC άνοιξε λίγο μετά την ώρα, δείξε την υπενθύμιση μέχρι τόσα λεπτά. Μετά την αγνοεί (όχι παλιά popup σε κάθε boot) |
| `sound` | `true` / `false` |
| `sound_seconds` | Διάρκεια ήχου (προεπιλογή 10). Κόβει και με «Το είδα» |

Παράδειγμα:

```json
{
  "store_name": "Κατάστημα Περιστέρι",
  "store_id": "peristeri",
  "ics_url": "https://calendar.google.com/calendar/ical/.../private-.../basic.ics",
  "ics_urls": [],
  "poll_seconds": 30,
  "minutes_before": 0,
  "show_missed_max_minutes": 15,
  "sound": true,
  "sound_seconds": 10
}
```

Τα βασικά πεδία αλλάζουν από tray → **Ρυθμίσεις** (ισχύουν αμέσως). Αν επεξεργαστείς το `config.json` με το χέρι: tray → **Έξοδος** και ξανά άνοιγμα της εφαρμογής (ή επανεκκίνηση).

## 3. Ποιο μαγαζί βλέπει ποιο μήνυμα

Στον **τίτλο** του γεγονότος στο Google Calendar:

| Τίτλος | Ποιος το βλέπει |
|---|---|
| `Παραλαβή κρέατος 12:00` | Όλα τα PC που έχουν αυτό το ICS |
| `[όλα] Άνοιγμα Κυριακής` | Όλα (`όλα` / `ola` / `all`) |
| `[peristeri] Ψυγείο 2` | Μόνο όσα έχουν `"store_id": "peristeri"` |
| `[peristeri,kalaamata] Προσφορά καφέ` | Αυτά τα δύο |

Το `store_id` και το κείμενο στις αγκύλες πρέπει να ταιριάζουν (λατινικά γράμματα ή/και αριθμοί, χωρίς τόνους· π.χ. `[12] Ψυγείο 2`). Στο παράθυρο φαίνεται ο τίτλος χωρίς τις αγκύλες.

Δεύτερο ημερολόγιο εργαζομένων: βάλε το ICS του **μόνο** στο `ics_urls` των PC εκείνου του μαγαζιού. Αλλιώς τα μηνύματά τους θα πάνε σε όλα τα καταστήματα.

## 4. Ήχος

Την πρώτη φορά που βγαίνει υπενθύμιση με `sound: true`, δημιουργείται `chime.wav` στον φάκελο της εφαρμογής (`%LOCALAPPDATA%\Ypenthimiseis`, ή δίπλα στο `app.py` αν τρέχει με Python). Απαλό δίφωνο κουδούνι κάθε ~3 δευτερόλεπτα.

Παίζεται με `winsound` από το αρχείο, όχι από τις ειδοποιήσεις Windows. Η ένταση ακολουθεί τα ηχεία του PC.

Μπορείς να αντικαταστήσεις το `chime.wav` με δικό σου wav (ίδιο όνομα). Αν το σβήσεις, ξαναφτιάχνεται το προεπιλεγμένο.

## 5. Συμπεριφορά «Το είδα» / «Σε 5 λεπτά»

- **Το είδα**: κλείνει στο συγκεκριμένο PC (`state.json`). Τα άλλα μαγαζιά δεν επηρεάζονται.
- **Σε 5 λεπτά**: ξανά στο ίδιο PC μετά από 5 λεπτά.
- Διαγραφή του γεγονότος από το Google Calendar: σταματά σε όλους στο επόμενο sync (έως ~30 δευτερόλεπτα).

Δεν υπάρχει κεντρική λίστα «ποιο μαγαζί το είδε».

## 6. Εκκίνηση και ενέργεια Windows

- Η εφαρμογή πρέπει να κάθεται στο system tray. Έξοδος μόνο από το μενού του εικονιδίου → **Έξοδος**.
- Ύπνος / αδρανοποίηση PC: όσο κοιμάται δεν βγαίνει υπενθύμιση. Μετά το ξύπνημα εμφανίζεται μόνο αν είστε μέσα στο `show_missed_max_minutes`.
- Οθόνη σβηστή αλλά PC ξύπνιο: δουλεύει.
- Στα καταστήματα κράτα τα PC ξυπνητά στο ωράριο.

## 7. Δοκιμή

Γεγονός στο σωστό ημερολόγιο σε 2–3 λεπτά, με ώρα. Μέσα σε περίπου 30 δευτερόλεπτα πρέπει να ανοίξει το παράθυρο και να παίξει ο ήχος.

Αν δεν εμφανίζεται: λάθος ημερολόγιο, Tasks αντί για Εκδήλωση, λάθος `store_id` στις αγκύλες, η εφαρμογή δεν τρέχει, ή το PC κοιμάται.

## Για προχωρημένους: εγκατάσταση με Python

Η παλιά μέθοδος δουλεύει ακόμη (π.χ. αν το antivirus δεν αφήνει το Setup). Αν τρέχει ήδη η έκδοση από το Setup, απεγκατέστησέ την πρώτα για να μην έχεις δύο εικονίδια.

### Απαιτήσεις

- Windows 10 ή 11
- Python 3.11+ (δοκιμασμένη και με 3.13 / 3.14)
- Εγκατάσταση Python με **Add python.exe to PATH**
- Internet στο PC του καταστήματος
- Ο λογαριασμός που δουλεύει στο ταμείο (απλός χρήστης αρκεί)

### Εγκατάσταση με Python

Γίνεται στον **απλό λογαριασμό του ταμείου**, όχι απαραίτητα ως διαχειριστής.

#### Α) Με install.bat

1. Εγκατάσταση Python από python.org, με PATH και tcl/tk.
2. Κατέβασε τον κώδικα (GitHub → **Code** → **Download ZIP**) και αποσυμπίεσέ τον.
3. Διπλό κλικ στο `install.bat`.
4. Στο μαύρο παράθυρο συμπληρώνεις:
   - όνομα καταστήματος
   - ID καταστήματος (λατινικά γράμματα ή/και αριθμοί, π.χ. `peristeri` ή `12`)
   - κεντρικό ICS URL
   - άλλα ICS (προαιρετικά, ένα ανά γραμμή — κενή γραμμή για τέλος)
   - δευτερόλεπτα ήχου (προεπιλογή 10)

Αντιγράφει την εφαρμογή σε:

`%LOCALAPPDATA%\Ypenthimiseis`

δηλαδή συνήθως:

`C:\Users\ΟΝΟΜΑ\AppData\Local\Ypenthimiseis`

Το `AppData` είναι κρυφό. Άνοιγμα φακέλου: `Win + R` → `%LOCALAPPDATA%\Ypenthimiseis`.

Βάζει συντόμευση στην Εκκίνηση των Windows (`ypenthimiseis-katastimaton.bat`) και ανοίγει την εφαρμογή στο tray.

Στα Windows 11: **Ρυθμίσεις → Εφαρμογές → Εκκίνηση** — η νέα εγγραφή συχνά είναι **Off**. Άνοιξέ την **On**. Αυτό είναι φυσιολογική συμπεριφορά του συστήματος.

#### Β) Χειροκίνητα

1. Φάκελος π.χ. `C:\Users\ΟΝΟΜΑ\ypenthimiseis` (όχι `Program Files`).
2. Αντιγραφή `app.py`, `requirements.txt`.
3. Δημιουργία `config.json` από το `config.example.json`.
4. `python -m pip install -r requirements.txt`
5. `python app.py`
6. Προαιρετικά `install_startup.bat` για εκκίνηση με τα Windows.

Αν η εντολή `python` δεν αναγνωρίζεται αλλά υπάρχει `py`:

```text
py -3 -m pip install -r requirements.txt
py -3 app.py
```

### Ενημέρωση της έκδοσης Python

1. Tray → **Έξοδος**.
2. Αντικατάσταση μόνο του `app.py` (και του `requirements.txt` αν άλλαξε).
3. `python -m pip install -r requirements.txt`
4. Κράτα το υπάρχον `config.json` και `state.json`.
5. Πρόσθεσε στο config όσα νέα πεδία λείπουν (`store_id`, `ics_urls`, `sound_seconds`).
6. Ξανά άνοιγμα.

Καθαρισμός για να ξαναστήσεις από την αρχή: Έξοδος → `shell:startup` διάγραψε το bat → σβήσε τον φάκελο εφαρμογής (`%LOCALAPPDATA%\Ypenthimiseis` ή όποιον χρησιμοποιούσες) → νέο `install.bat`.

Αν μετά την ενημέρωση βλέπεις δύο εικονίδια, υπάρχουν δύο συντομεύσεις Εκκίνησης. Κράτα μία.

### Χτίσιμο του Setup.exe

Γίνεται αυτόματα στο GitHub Actions σε κάθε push· με tag `v*` (π.χ. `v1.0.0`) ανεβαίνει και στα Releases. Τοπικά σε Windows με Python 3.12 και Inno Setup 6:

```text
powershell -ExecutionPolicy Bypass -File installer\build.ps1
```

Αποτέλεσμα: `installer\Output\Ypenthimiseis-Setup.exe`.
